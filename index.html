CLASE 4: LISTAS Y TABLAS DE DATOS EN HTML5

Objetivo de la Clase 4: Dominar la maquetación de listas estructuradas y la construcción de tablas de datos complejas mediante etiquetas semánticas de agrupación y combinación de celdas (colspan y rowspan), integrándolas dentro de la estructura general de una página web.

1. Listado de Etiquetas de la Clase 4 y Explicación Guiada

A. Explicación Detallada de las Etiquetas de Listas (<ul>, <ol>, <li>, <dl>, <dt>, <dd>)

Las listas permiten agrupar elementos relacionados dentro del cuerpo principal de la página de forma ordenada o descriptiva. A continuación se detallan todas sus etiquetas:

  • <ul> (Unordered List): Define una lista desordenada donde el orden de los elementos no altera el significado (ej. opciones de menú dentro de <nav>). Visualmente utiliza viñetas o puntos.
  • <ol> (Ordered List): Define una lista ordenada donde la secuencia importa (pasos de un proceso, posiciones, rankings). El navegador asigna números de forma automática.
  • <li> (List Item): Representa un elemento individual dentro de una lista. Solo puede ir contenido de manera directa dentro de un <ul> o un <ol>.
  • <dl> (Description List): Define una lista de descripción o glosario. Actúa como el contenedor principal para agrupar términos y sus respectivas explicaciones.
  • <dt> (Definition Term): Especifica el término o concepto dentro de una lista de descripción (<dl>).
  • <dd> (Definition Description): Proporciona la definición o explicación detallada correspondiente al término (<dt>) previamente declarado.

B. Etiquetas de Tablas (<table>, <thead>, <tbody>, <tfoot>, <tr>, <th>, <td>, <caption>)

Las tablas representan datos tabulares en filas y celdas. Su estructura moderna se divide en tres secciones semánticas clave:

  • <table>: Contenedor general de la tabla.
  • <caption>: Título descriptivo o pie explicativo de la tabla.
  • <thead>: Encabezado de la tabla (alberga los nombres de las columnas).
  • <tbody>: Cuerpo principal donde residen los datos tabulares.
  • <tfoot>: Pie de tabla (totales o resúmenes).
  • <tr> (Table Row): Fila horizontal dentro de la tabla.
  • <th> (Table Header): Celda de encabezado (texto centrado y en negrita).
  • <td> (Table Data): Celda estándar con los datos de la fila.
  • Atributos de expansión: colspan="N" expande una celda horizontalmente a través de N columnas; rowspan="N" expande una celda verticalmente a través de N filas.
REGLA DE ORO DEL DOCENTE: ¿Cuándo utilizar y cuándo NO utilizar tablas?
• SÍ utilizar: Para representar datos tabulares puros (horarios, reportes de inventario, listas de precios, horarios escolares, calendarios, tablas comparativas).
• NO utilizar: Para diseñar la estructura o maquetación visual de una página web. Para estructurar la interfaz usamos la maquetación semántica oficial (header, nav, article, section, aside, footer).

2. Listado de Etiquetas de la Clase 5 y Explicación Guiada

A. Etiquetas Semánticas Estructurales y de Sección

  • <header>: Bloque superior de la página web. Alberga el logotipo principal y los títulos de bienvenida.
  • <nav>: Sección inmediatamente inferior a la cabecera que agrupa el menú de enlaces principales.
  • <article>: Contenedor del bloque central de la página. Encapsula el contenido temático de la noticia o publicación.
  • <section>: Sub-divisiones temáticas dentro del <article>. Cada sección representa un capítulo o apartado específico.
  • <aside>: Panel lateral independiente ubicado al lado del contenedor central. Contiene información secundaria, enlaces recomendados o widgets.
  • <footer>: Pie de página de extremo a extremo. Incluye derechos de autor, aviso legal, accesibilidad y datos de contacto en <address>.
  • <figure> y <figcaption>: Envolvente semántico para imágenes o diagramas con leyenda explícita.
  • <time>: Representa fechas legibles para máquinas mediante el atributo datetime.
Diferencia Fundamental: <div> vs. Elementos Semánticos
• <div>: Es un contenedor neutro sin significado semántico. Se debe usar únicamente cuando se requiere aplicar estilos visuales con CSS o manipular la interfaz con JavaScript sin aportar un significado estructural.
• Elementos Semánticos (<article>, <section>, etc.): Le explican al navegador, a los lectores de pantalla para personas con discapacidad visual y a motores de búsqueda como Google qué función cumple cada parte de la página web.
